# 🌟 عادل - لعبة المغامرات التعليمية

لعبة HTML5 تعليمية ومغامرات موجهة للأطفال من عمر 5 إلى 12 سنة.

---

## 🚀 كيفية التشغيل

### تشغيل محلي
1. افتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome, Firefox, Safari, Edge)
2. أو استخدم أي خادم محلي بسيط:
   ```bash
   npx serve .
   # أو
   python3 -m http.server 8080
   ```

### نشر على GitHub Pages
1. ارفع المشروع كاملاً إلى repository على GitHub
2. اذهب إلى **Settings → Pages**
3. اختر **Branch: main** ومجلد **Root**
4. انقر **Save**
5. اللعبة ستكون متاحة على: `https://username.github.io/repo-name`

## 🛠️ التطوير والتخصيص

### إضافة مستوى جديد
في ملف `data/gameData.js`، أضف كائناً جديداً في مصفوفة `LEVELS_DATA`:

```javascript
{
  id: 8,
  name: 'مستواي الجديد',
  emoji: '🌈',
  description: 'وصف المستوى...',
  bgColor: ['#FFE0B2', '#FF9800', '#E65100'],
  groundColor: '#4CAF50',
  groundDark: '#388E3C',
  collectibles: [
    { emoji: '🌸', name: 'زهرة', points: 15, growth: 5 },
  ],
  obstacles: ['🪨'],
  target: 10,
  statBonus: { skill: 10, growth: 5 },
}
```

### إضافة إنجاز جديد
في `data/gameData.js` في مصفوفة `ACHIEVEMENTS_DATA`:

```javascript
{
  id: 'my_achievement',
  icon: '🌈',
  name: 'إنجازي الجديد',
  desc: 'وصف الشرط لفتح هذا الإنجاز',
  condition: (state) => state.stars >= 200,
}
```

### إضافة شخصية جديدة
يكفي رفع صورة جديدة عبر واجهة اللعبة. النظام مصمم ليدعم:
- صور مختلفة لكل جلسة
- ألوان ملابس مخصصة
- أسماء متعددة

### إضافة لغة جديدة
1. أنشئ ملف `data/lang/en.js` (أو أي لغة)
2. انسخ جميع النصوص العربية وترجمها
3. أضف منتقي اللغة في صفحة الإعدادات
